# MyBlog 个人博客静态页面

> 基于 HTML5 + CSS3 实现的简易个人博客前端页面，原生无框架，语义化标签，支持移动端自适应。

## 📋 项目简介
这是一个轻量静态博客首页，只包含前端展示代码，**没有后端、没有数据库**。
- 使用 HTML5 语义化标签编写页面结构
- CSS Flexbox 实现布局，卡片式文章列表
- 自带响应式适配：平板、手机自动调整排版
- 卡片悬浮动画、链接 hover 过渡交互效果
- 适合作为前端练手项目，可在此基础上扩展文章详情页、搜索等功能。

## 📁 项目文件结构
MyBlog/
├── index.html      # 博客首页 HTML 结构文件
├── style.css       # 全部样式表文件
└── README.md       # 项目说明文档

## ✨ 功能特性
1. **页面结构**
    - 顶部导航页眉：博客Logo + 导航菜单（首页 / 文章 / 关于 / 联系）
    - 主内容区：卡片式文章列表，包含标题、发布日期、标签、摘要、阅读全文链接
    - 底部页脚：版权声明

2. **样式交互**
    - 蓝紫渐变导航栏，卡片阴影悬浮上浮效果
    - 全局盒子模型重置，兼容不同浏览器默认样式
    - 系统无衬线字体栈，跨平台文字显示友好

3. **响应式适配**
    - `≤768px` 平板：导航改为上下居中堆叠，卡片内边距缩小
    - `≤480px` 手机：导航间距缩小，文章日期标签自动换行，防止小屏拥挤

## 🚀 快速运行
1. 将两个文件放在**同一个文件夹**下
2. 直接双击打开 `index.html`，即可在浏览器查看博客页面

> ⚠️ 当前所有链接都是占位符 `#`，点击只会回到页面顶部，需要手动修改为真实页面路径。

## 📝 开发修改指南
### 修改页面内容
编辑 `index.html`：
- 修改博客名称：`<h1>📝 MyBlog</h1>`
- 新增/删除文章：复制 `<article class="blog-post">...</article>` 整块即可
- 修改导航菜单：修改 `<li>` 里面的文字与 `href` 属性

### 修改样式主题
编辑 `style.css`：
- 主题色：渐变颜色 `#667eea`、`#764ba2`，可替换成自己喜欢的配色
- 调整卡片圆角、阴影、间距等样式参数
- 修改断点：`@media (max-width:768px)`、`@media (max-width:480px)` 修改响应式触发尺寸
